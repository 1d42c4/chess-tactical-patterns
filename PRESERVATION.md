# Preservation

The published `main` branch and version tags are protected against updates, force pushes and deletion with GitHub rulesets. Independent Git bundles and source archives are kept outside GitHub.

These controls protect the published branch and tags. A repository owner can still change the rules or delete the entire repository; GitHub branch rules cannot make an owner account deletion-proof.

For a deliberate correction, retain the existing release and backup, review the lesson and position data, temporarily change the appropriate rule as owner, publish a new version, and restore protection. Do not silently replace a tagged edition.
